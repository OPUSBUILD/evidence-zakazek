# Evidence zakázek 2026

Interní webová aplikace společnosti **OPUS BUILD s.r.o.** pro evidenci požadavků a zakázek.

- Aplikace: https://opusbuild.github.io/evidence-zakazek/
- Přístup jen pro přihlášené uživatele OPUS BUILD; data jsou uložena v zabezpečeném cloudu, ne v tomto repozitáři.
- Celá aplikace je v souboru `index.html`.

## Aktuální verze
**v3.4** (3. 10. 2026) – pojistky dat: offline režim jen pro čtení, úpravy podle ID zakázky, DUZP z protokolu jen po potvrzení, technici v nabídce, export Excel celé evidence, bezpečný výpis textu.

## Nasazení nové verze
1. V aplikaci stáhnout **Záloha dat**.
2. Nahrát nový `index.html` do tohoto repozitáře (větev `main`).
3. Po 1–2 minutách otevřít aplikaci, **Ctrl+F5** a ověřit číslo verze v hlavičce.
